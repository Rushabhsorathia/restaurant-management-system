## How To Use This Index

1. **Find a ticket** — browse the milestone tables or use Ctrl+F
2. **Open the ticket** — click the link to read full story, AC, UI screens, API endpoints, DB tables, subtasks, and testing criteria
3. **Track dependencies** — each ticket lists its dependencies; check those before starting
4. **Update status** — change `To Do` to `In Progress` / `Done` in the ticket header table as work progresses
5. **Module mapping** — use the cross-reference table to find all tickets touching a specific module
